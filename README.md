# 🇳🇱 Amsterdam — interaktívna cestovná mapa

Interaktívna mapa pre výlet do Amsterdamu (13.–15. júna 2026). Jeden HTML súbor,
žiadna inštalácia — stačí otvoriť `index.html` v prehliadači.

## Funkcie
- 90+ kurátorovaných miest (gastro, brown café, coffee shopy, nákupy, zážitky,
  architektúra, príroda…) s overenými adresami a presnými polohami
- Filter podľa dní (So / Ne / Po) a kategórií
- Sidebar s fotkou, hodnotením, cenou, hodinami a popisom
- Plán dňa + režim itinerára (číslované zastávky, pešie vzdialenosti a časy)
- „Moja poloha", vyhľadávanie, satelitná mapa, POI vrstva
- Pridávanie / úprava / mazanie vlastných miest (uložené v `localStorage`)

## Stack
[Leaflet.js](https://leafletjs.com/) · CartoDB / ESRI dlaždice ·
OpenStreetMap Nominatim (geocoding) · Inter font. Bez platených API.

## Spustenie
Otvor `index.html` v prehliadači, alebo nasaď na GitHub Pages.
